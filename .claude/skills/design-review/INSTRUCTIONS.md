# design-review Instructions

## 事前読み込み

1. HIG リファレンス:
   - `.claude/skills/_shared/design/hig-ios.md`
2. デザインプロトタイプ (参照用):
   - `calame-design-final.jsx` — React ベースのデザインプロトタイプ (UIの参考)
3. 設計ドキュメント:
   - `docs/DESIGN.md` — UI/UX 方針

## レビュー対象の特定

### SwiftUI コードレビュー
```bash
# Feature の View ファイル
find Packages/CalameKit/Sources/Features -name "*View.swift"

# SharedUI コンポーネント
find Packages/CalameKit/Sources/SharedUI -name "*.swift"

# App 固有の View
find App -name "*View.swift"
```

### デザインプロトタイプとの照合
- `calame-design-final.jsx` をデザイン意図の参考として参照
- SwiftUI 実装がデザイン意図を正しく反映しているか確認

## レビュー観点

### 1. Calame 固有の UX チェック

#### メニューバーポップオーバー (macOS)
- [ ] ポップオーバーのサイズが適切か (大きすぎない)
- [ ] 表示/非表示のトランジションがスムーズか
- [ ] キーボードショートカットで開閉できるか
- [ ] ポップオーバー外クリックで閉じるか
- [ ] メニューバーアイコンが Template Image か
- [ ] 録音状態がメニューバーアイコンに反映されるか

#### 録音フィードバック
- [ ] 録音中の視覚的フィードバックが明確か (波形、アニメーション)
- [ ] 録音開始/停止の状態遷移がわかりやすいか
- [ ] 音声レベルのリアルタイム表示があるか
- [ ] 録音中にキャンセルできるか
- [ ] 録音完了後のテキスト表示が自然か

#### フローティングプレビュー
- [ ] テキスト変換中のプレビューが読みやすいか
- [ ] プレビューの表示位置が適切か (入力フィールドの近く)
- [ ] プレビューの表示/非表示がスムーズか
- [ ] 長いテキストの場合のスクロール/切り詰め

#### Keyboard Extension UI (iOS)
- [ ] キーボードサイズが標準的か
- [ ] 録音ボタンが押しやすい位置とサイズか
- [ ] テキストプレビュー領域が十分か
- [ ] 標準キーボードとの切り替えがスムーズか
- [ ] ダークモード / ライトモード対応

### 2. HIG 準拠

- [ ] システムカラーを使用しているか
- [ ] SF Symbols を使用しているか
- [ ] Dynamic Type 対応か
- [ ] ダークモード対応か
- [ ] アクセシビリティ (VoiceOver, アクセシビリティラベル)
- [ ] 最小タッチターゲット (44x44pt)
- [ ] 標準コンポーネントを優先しているか

### 3. プラットフォーム固有

#### macOS
- [ ] メニューバーアプリとしての慣例に従っているか
- [ ] ウインドウリサイズ対応
- [ ] キーボードショートカット
- [ ] 右クリックメニュー (必要な場合)

#### iOS
- [ ] Safe Area 対応
- [ ] 横向き対応 (必要な場合)
- [ ] iPad 対応 (必要な場合)
- [ ] ジェスチャーが直感的か

### 4. SwiftUI 実装品質

- [ ] `@Observable` / `@Bindable` の正しい使用
- [ ] 不要な再描画がないか
- [ ] アニメーションが `.animation()` で適切に管理されているか
- [ ] `withAnimation` の使い方が適切か
- [ ] Preview が定義されているか

### 5. 一貫性

- [ ] カラーパレットが統一されているか
- [ ] スペーシング・マージンが一貫しているか
- [ ] フォントサイズ・ウェイトが統一されているか
- [ ] アイコンのスタイルが統一されているか
- [ ] インタラクションパターンが統一されているか
