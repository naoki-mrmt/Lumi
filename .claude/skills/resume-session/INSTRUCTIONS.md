# resume-session Instructions

## 復元フロー

### 1. セッションファイルの特定

```bash
# 最新のセッションファイル
ls -t .claude/sessions/*.md | head -1

# 一覧表示
ls -la .claude/sessions/
```

ユーザーが特定ファイルを指定した場合はそちらを使用。

### 2. セッションファイルの読み込み

セッションファイルから以下を抽出:
- 作業内容の概要
- 進行中のタスク
- 次にやること
- ブロッカー
- 関連ファイル

### 3. 現在の状態との差分確認

```bash
# 現在のブランチ
git branch --show-current

# セッション保存時からの変更
git log --oneline {session-commit}..HEAD

# 現在のワーキングツリー
git status
```

### 4. ROADMAP の最新状態を確認

`docs/ROADMAP.md` を読み込み、セッション保存時からの進捗変化を確認。

### 5. コンテキスト復元サマリーの出力

```markdown
## セッション復元: {summary}

### 前回の状態
{セッションファイルの要約}

### 現在との差分
- ブランチ: {前回} → {現在}
- 新しいコミット: {件数}

### 次にやること
1. {タスク1} — {詳細}
2. {タスク2} — {詳細}

### 関連ファイル (確認推奨)
- {ファイル1}
- {ファイル2}
```

## 注意事項
- セッションファイルが見つからない場合は、その旨を伝えて新規セッションの開始を提案
- ブランチが変わっている場合は警告
- 古いセッション (1週間以上) の場合は、ROADMAP の再確認を推奨
