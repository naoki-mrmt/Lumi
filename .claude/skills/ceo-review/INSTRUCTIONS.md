# ceo-review Instructions

## 事前読み込み

1. `docs/DESIGN.md` — 設計思想、技術選定、競合ポジション
2. `docs/ROADMAP.md` — フェーズ計画、マイルストーン
3. 現在のコード状態を概観:
   ```bash
   find Packages/CalameKit/Sources -name "*.swift" | wc -l
   find App -name "*.swift" | wc -l
   git log --oneline -20
   ```

## 評価軸

### 1. ユーザー価値 (Voice Input UX)

**評価ポイント:**
- 音声入力の精度と速度 (WhisperKit の活用度)
- テキスト変換・補正の品質 (llama.cpp の活用度)
- 入力から確定までのフロー (ストローク数、待ち時間)
- カスタム辞書・プロファイルの有用性
- Keyboard Extension の使い勝手

**質問:**
- ユーザーが既存のキーボード入力の代わりに使いたいと思えるか？
- 初回起動から価値を感じるまでの時間は？

### 2. プライバシー・ローカル処理

**評価ポイント:**
- すべての音声処理がデバイス上で完結しているか
- データがデバイス外に送信されないことの保証
- SwiftData のローカル保存の適切さ
- プライバシーポリシーの訴求力

**質問:**
- 「プライバシーファースト」を信頼性のある形で訴求できるか？
- クラウド依存の競合に対する明確な差別化になっているか？

### 3. 競合分析

**主要競合:**
- **Aqua Voice** — AI音声入力、クラウドベース
- **Eloquent** — macOS 音声入力、ローカル処理
- **VoiceInk** — macOS 音声入力アプリ
- **Apple Dictation** — OS 標準機能

**比較軸:**
| 軸 | Calame | Aqua Voice | Eloquent | VoiceInk | Apple Dictation |
|----|--------|------------|----------|----------|-----------------|
| プライバシー | ローカル完結 | クラウド | ローカル | ? | ハイブリッド |
| プラットフォーム | macOS+iOS | macOS | macOS | macOS | macOS+iOS |
| カスタマイズ | 辞書+プロファイル | ? | ? | ? | 限定的 |
| 価格 | ? | サブスク | 買い切り | ? | 無料 |

### 4. macOS + iOS デュアルプラットフォーム戦略

**評価ポイント:**
- macOS: メニューバーアプリとしての完成度
- iOS: Keyboard Extension としての実用性
- 両プラットフォーム間の体験の一貫性
- iCloud 同期の必要性 (将来)

### 5. 技術基盤の成熟度

**評価ポイント:**
- WhisperKit の安定性とモデルサイズ
- llama.cpp のデバイス上パフォーマンス
- SwiftData のスケーラビリティ
- Keyboard Extension のメモリ制約への対応

### 6. Go-to-Market 準備度

**評価ポイント:**
- MVP の定義と現在の達成度
- App Store 提出に必要な残作業
- マーケティングメッセージの明確さ
- ベータテストの計画
