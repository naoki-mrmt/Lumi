# PR テンプレート

## タイトルフォーマット

```
<type>(<scope>): <概要>
```

概要は日本語OK。例:
- `feat(kit): WhisperKit統合の実装`
- `feat(mac): メニューバーUIの実装`
- `fix(kit): 音声エンジンクラッシュの修正`

## 本文テンプレート

PR は日本語で作成する。

```markdown
## 概要

{この PR で何を実現するかを1〜2文で記述}

## 変更内容

- {変更1}
- {変更2}
- {変更3}

## テスト

- [ ] ユニットテスト通過
- [ ] ビルド成功
- {その他テスト結果があれば記載}

## 関連タスク

- docs/tasks/phaseN.md: {タスク名}
```

## 注意事項

- 関連タスクは docs/tasks/ のフェーズとタスク名を参照する
