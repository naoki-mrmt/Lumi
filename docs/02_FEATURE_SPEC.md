# 02. Feature Specification

> Phase別・優先度別の機能一覧。MoSCoW（MUST / SHOULD / COULD / WON'T）で整理。

## 凡例

- **MUST**：そのPhaseで絶対に必要（リリース不可ならMUST未達）
- **SHOULD**：そのPhaseで望ましいが、リリース可能性は脅かさない
- **COULD**：余裕があれば
- **WON'T**：明示的にやらない

---

## Phase 1.0: MVP（実戦投入レベル）

### Phase 1.0 MUST

#### F-1.0.1 チーム・選手マスタ管理
- 自チームの選手登録（最大15人）
- 選手情報：背番号・名前・ポジション傾向（任意）
- 選手の追加・編集・物理削除（確認ダイアログ付き）

#### F-1.0.2 試合作成・管理
- 試合のメタ情報：日付・対戦相手・大会名・**試合タイプ・会場**
- スタメン9人選択（チームマスタから）
- 前回試合からのスタメンコピー機能
- サービス順設定（ドラッグ&ドロップ）
- フォーメーション選択（5-1-3 / 6-3 / 4-2-3 / 3-3-3 / その他カスタム）
- 相手チーム背番号登録（任意・スキップ可、9人想定）

#### F-1.0.3 9人制ルール対応
- サービス順自動算出（順番リスト方式）
- セット間引き継ぎ（前セット最終サーバーの次が初手）
- 選手交代時の順番引継ぎ（4回/セット、最大3人/回）
- 同セット内の再交代制限
- 2回サーブ制（1stサーブ失敗 → 2ndサーブ）
- ブロックも接触1回（タッチ回数管理）
- 21点3セットマッチ（20-20でデュース、2点差まで）
- フリーポジション前提のデータモデル

#### F-1.0.4 入力UI（3モード）

**クイックモード**
- 得点経緯のみ：誰がサーブ・誰が決めた・誰がミス
- 1ラリー2-3タップ
- 主にママさん・練習試合向け

**スタンダードモード（デフォルト）**
- サーブ：選手・種類（フローター/ジャンプ/ジャンプフローター）・評価
- レセプション：選手・返球位置（A/B/C/Dパス）・評価
- アタック：打者・評価
- ブロック：枚数・評価
- ディグ：選手・評価
- セット：選手・評価
- ミス：選手・種別（ドリブル等は1カテゴリ）

**詳細モード**
- スタンダード + 以下：
  - アタックコース（クロス/ストレート/インナー/フェイント）
  - サーブコース（相手コートゾーン）
  - 相手のアタック・サーブコース

#### F-1.0.5 ラリータイムライン入力
- 1ラリーをタイムラインとして表示
- 自チーム/相手チームを1タップ切替
- 「+ プレー追加」で詳細プレーを記録
- ラリー終了時に得点付与チームを選択

#### F-1.0.6 アンドゥ・編集
- 直前のプレーを1タップでアンドゥ（最大5ステップ）
- 直前のラリー全体を編集（編集モード）
- 2つ以上前のラリーは試合中編集不可

#### F-1.0.7 タイムアウト記録
- TOボタン1タップで記録
- 自/相手・スコア（自動取得）・タイプ（タイムアウト/メディカル）
- 1セット2回上限のチェック・UI制限
- 任意メモ欄なし（シンプル維持）

#### F-1.0.8 リアルタイムKPI表示

ベンチ閲覧iPadに常時表示：
- アタック決定率・効果率（両方）
- レセプションA率・返球率
- サーブ得点・サービスエフィシェンシー
- ブロック数
- ディグ成功率
- セット成功率
- 連続得点（**3点以上連続でハイライト**）
- セット別・選手別・フォーメーション別

#### F-1.0.9 アシスト自動計算
- 決定打の直前のセットを自動でアシスト判定
- 入力負荷ゼロでセッター貢献度を可視化

#### F-1.0.10 Recorder/Viewer ロール分離
- **Recorder**：1端末のみ・アカウント必須・入力可能
- **Viewer**：複数端末OK・試合コードのみで参加・読み取り専用
- Recorder衝突防止（後から入った端末は自動Viewer）

#### F-1.0.11 認証
- Sign in with Apple（Recorder必須）
- Apple ID未保有者向けにメール認証は Phase 2 で追加

#### F-1.0.12 試合コード共有
- 試合作成時に6桁試合コード自動発行
- Viewer は試合コードを入力して参加
- 試合終了から24時間で失効（セキュリティ）

#### F-1.0.13 リアルタイム同期
- Supabase Realtime 経由でプレー入力を即時配信
- レイテンシ目標2秒以内
- オフライン時はローカルバッファ → 復帰時自動再送

#### F-1.0.14 オフライン耐性
- Recorder：完全オフラインで試合完遂可能
- Viewer：オフライン時は最終受信データを表示・「未接続」明示
- 復帰時：自動同期・差分のみ送信

#### F-1.0.15 試合後の振り返り画面
- ライブビュー → 振り返りビューの自動切替（試合終了時）
- 主要KPI・選手別詳細・セット別比較・得点推移グラフ
- 連続得点ハイライト・タイムアウトマーカー

#### F-1.0.16 PDF / CSV 出力
- 試合サマリPDF（A4・1〜2枚）：スコア・主要KPI・選手別簡易表
- 選手別集計CSV：全プレーログ + 集計値
- iOSの共有シート経由でAirDrop/メール/LINE等に共有

#### F-1.0.17 動画後付け同期
- ファイルアップロード（mp4/mov）
- 試合開始時刻を1点合わせる
- 各プレーのタイムスタンプから自動シーン抽出
- 数値クリック→該当シーン再生（簡易版）

#### F-1.0.18 エラーハンドリング・障害時UX（M7）

すべて Phase 1.0 MUST：
1. ネット一時切断時のオフライン継続
2. Supabase書き込み失敗時のバッファ・再送
3. 試合コード誤入力時のメッセージング
4. **Recorder アプリクラッシュ時のリカバリ**（10秒ごとローカル保存・起動時復元）
5. バッテリー切れ警告（残量20%以下）
6. iCloudバックアップ失敗の通知
7. Sign in with Apple失敗時のフォールバック導線
8. 同一試合への2人目Recorder検知
9. データ整合性バリデーション
10. アプリアップデート時のスキーマ自動マイグレーション

#### F-1.0.19 観測性（M8）
- Sentry によるクラッシュ検知
- 重大エラーの手動キャプチャ
- OSLog によるアプリ内ログ

#### F-1.0.20 多言語化基盤
- String Catalog（iOS 26）で日英対応の基盤を構築
- 提供は日本語のみ（英語キーは空でも構わない）

#### F-1.0.21 試合削除の安全機構
- 物理削除（シンプル）
- 削除前に試合名入力で確認
- 削除前にローカルにJSONバックアップ自動生成（Filesアプリ保存）

### Phase 1.0 SHOULD

- F-1.0.S1 タイムアウト時のフォーメーション変更記録
- F-1.0.S2 連続得点ハイライト閾値のカスタマイズ
- F-1.0.S3 試合中の任意メモ機能（試合全体に対する1フィールド）

### Phase 1.0 WON'T
- ❌ ローカルルール（3点連続交代）対応
- ❌ アタッカー打点高さ
- ❌ 自動ビデオタギング
- ❌ ローテ別分析（9人制では不要）
- ❌ iPhone対応

## Phase 2.2: 試合後の振り返り体験

### Phase 2.2 MUST

- F-2.2.1 数値クリック→動画該当シーン即再生（本格版）

- F-2.4.4 App Store公開

## 全Phase通しての WON'T（明示的にやらない）

- ❌ 6人制対応
- ❌ AIによる自動プレー判定
- ❌ Windows / Android 対応
- ❌ ローカルルール（地域独自）の網羅対応
- ❌ ライブ配信の無線対応（WebRTCのSaaS依存）
- ❌ Twitter/X など SNS への直接投稿機能
